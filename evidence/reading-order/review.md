# Review

Levels: **MA** meta-analysis · **RCT** randomised experiments · **S** single study · **R** review without pooling · **T** theory or model with no controlled test.

**(secondary)** marks a number read in a summary, not in the paper.

Surveys to read first: Ponce 2025 (organizers), McCrudden 2007 (relevance), Rittle-Johnson 2015 (order of lessons), Loibl 2017 (problem first), Wickens 2013 (part-task training), Rayner 2016 (skimming), Brunmair 2019 (interleaving).

| Source | Finding | Level |
|---|---|---|
| Luiten 1980; Stone 1983 | advance organizer: learning d = 0.21, retention 0.26 over 135 studies (secondary, read in Kenny 1993); 0.66 on delayed tests only (secondary); needs unfamiliar material | MA |

| Harden and Stamper 1999 | spiral curriculum; single-site, quasi-experimental evidence | T |

## 3. Order within a unit

| Source | Finding | Level |
|---|---|---|
| Rittle-Johnson and Koedinger 2009; Rittle-Johnson 2015 | alternating concept and procedure lessons beat concepts first on procedures and transfer; concepts equal (N = 77, 26) | RCT; R |
| van Gog 2011 | example then paired problem beat problems only; problem then example did not | RCT |
| Ashman 2020 | when many elements interact, instruction then problem beat the reverse (2 experiments) | RCT |
| Sinha and Kapur 2021; Loibl 2017 | problem first g = 0.36; only with contrasting cases or instruction built on the attempt | MA; R |
| Fyfe 2014; McNeil and Fyfe 2012 | concrete then abstract: no pooled effect; one positive transfer experiment | R; S |
