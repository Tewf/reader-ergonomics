# Frame

## The problem, one sentence

Which typographic and layout choices (line length, size, spacing, contrast, structure, figures) change how fast, how accurately and how comfortably people read on screen?

## Terms used in this folder

- **cpl**: characters per line, spaces included.
- **ch**: a CSS unit equal to the width of the digit "0"; a line of 70ch holds more than 70 average letters.
- **Contrast ratio**: (L1 + 0.05) / (L2 + 0.05) for relative luminances, from 1:1 to 21:1.
- **Effect size**: d or g, a standardised mean difference. **MA**: meta-analysis. **RCT**: randomised experiments. **S**: single study. **R**: review. **P**: practitioner opinion.
