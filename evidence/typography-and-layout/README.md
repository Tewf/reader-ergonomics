# Typography and layout for on-screen reading

How should text be set and laid out so a reader reads it fast, accurately and comfortably? The field calls this legibility, readability and accessible design.

Steps: [frame](frame.md) · [review](review.md) · [state of the art](state-of-the-art.md) · [position](position.md) · [against](against.md) · [baseline](baseline.md) · [bibliography](../bibliography.md)
