# Principles

The general optimum, one file per principle, grouped by the scale it acts on. Each file follows
the same shape: the claim, its grade, the evidence, the check that enforces it, the reader styles
that override it; then what it asks, why, and its limits.

| Facet | Scale |
|---|---|
| [collection/](collection/) | how content is cut into files and arranged in folders |
| [document/](document/) | the order and depth of one document |
| [sentence/](sentence/) | how information is packed into sentences |
| [page/](page/) | figures, layout and type on the page |

The claims and grades of all of them, in one table, are in the [standard](../standard.md).
